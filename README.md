# MahjongHelper – 麻将辅助工具（GUI版）

一个基于屏幕实时识别、能够自动分析手牌并给出切牌建议的麻将辅助工具。  
支持**手动框选识别区域**，**自动/手动刷新**，以及**模板在线修正**，帮助您更高效地练习或娱乐。

---

## ✨ 主要功能

- **实时屏幕识别**：截取指定区域内的麻将牌面，自动识别每张牌的花色与数值。
- **智能切牌建议**：基于“关联度”算法，计算打出哪张牌能使剩余牌形成更多顺子、刻子、对子，并给出最优建议。
- **交互式修正**：如果识别有误，可直接通过牌下方的下拉栏选择正确牌，程序自动更新模板并刷新识别，越用越准。
- **直观视觉反馈**：被建议打出的牌其标签文字会显示为**绿色**，其余为白色，一目了然。
- **便捷热键**：F2 框选区域，F1 刷新识别，ESC 取消操作，全程无需鼠标。
- **系统托盘常驻**：自动隐藏至系统托盘，左键可随时调出主界面查看结果。

## 📦 安装与配置

### 1. 克隆或下载本项目

```bash
git clone https://github.com/toki-2004/MahjongHelper.git
cd MahjongHelper
```

### 2. 安装 Python 依赖

建议使用虚拟环境（如 `venv`）：

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# 或 source venv/bin/activate  # Linux/macOS
```

然后安装依赖：

```bash
pip install -r requirements.txt
```

如果尚未生成 `requirements.txt`，请手动安装以下核心库：

```bash
pip install PyQt5 mss opencv-python numpy keyboard
```

### 3. 准备模板图片

程序需要 `templates/` 文件夹下存放 **34 张** 麻将牌的模板图片（`0.png` ~ `33.png`），用于识别比对（已预存默认图片）。  
- 如果你已有模板，直接放入该目录即可。  
- 如果没有，程序启动时会自动生成 **纯白色占位模板**，但识别将无法正常工作。  
  你需要准备一套完整的牌面图片（建议从实际游戏中截图裁剪，每张牌只含牌面图案，尺寸统一）。

> 💡 模板图片建议尺寸：**宽50px，高70px**，格式为 PNG，背景透明或纯色。

## 🚀 使用方法

### 1. 启动程序

以**管理员身份**运行命令行（确保全局热键生效），进入项目目录后执行：

```bash
python main.py
```

程序启动后：
- 系统托盘会出现一个电脑图标，鼠标悬停显示“麻将辅助工具”。
- 主界面（“麻将辅助 - 识别结果”）会自动弹出。

### 2. 框选识别区域

按下键盘上的 **F2**，屏幕会变暗并出现十字光标。  
**按住鼠标左键拖拽**，框出你手中所有牌所在的区域（尽量只包含牌面，周围少留空白）。  
释放鼠标后，程序会自动截取该区域并开始识别。

> 框选一次后，区域会被保存到 `config.json`，下次启动会自动加载。

### 3. 查看识别结果

识别完成后，会在你框选的区域上方叠加显示：
- 每张牌下方会显示其牌名（如 `1p`、`2w`、`3s` 等）。
- **绿色牌名** 表示建议打出的牌。
- 主界面右侧会同步显示手牌列表和详细建议（含得分）。

### 4. 修正错误识别

如果某张牌被识别错误，在对应牌的下方有一个 **下拉栏**（ComboBox），里面列出了所有 34 种牌（带序号和名称）。  
点击下拉栏，选择正确的牌，程序会：
- 自动将当前截取的该牌图像与原有模板融合更新。
- 重新识别一次，刷新结果。

随着使用过程中不断修正，识别准确率会逐步提升。

### 5. 刷新识别

如果牌面发生变化（如摸牌、出牌），按 **F1** 即可重新识别当前框选区域，无需重新框选。

### 6. 切换识别模式

右键点击系统托盘图标 → **设置**，可选择：
- **手动 (F2 框选)**：需要手动按 F2 重新框选（默认）
- **自动 1s / 2s / 3s**：程序每隔指定时间自动识别当前区域，适合快速连续场景。

### 7. 退出程序

右键点击系统托盘图标 → **退出**，即可完全退出程序。

## ❓ 常见问题

**Q：启动时提示“建议以管理员身份运行”？**  
A：全局热键（F2、F1、ESC）需要管理员权限才能注册。请在命令行或快捷方式上右键选择“以管理员身份运行”。

**Q：识别结果一直不准或乱码？**  
A：最可能是模板图片与当前游戏中的牌面风格差异太大。请多使用**下拉栏修正**功能，程序会自动融合模板，经过数次修正即可匹配。

**Q：框选后没有反应，或识别出 0 张牌？**  
A：请确保：
- 框选区域只包含牌，不含过多背景。
- 牌与牌之间留有小间隙，不要完全紧挨。
- 牌面亮度适中，无强烈反光。

**Q：下拉栏点击后没有弹出选项？**  
A：请确保鼠标点击位置准确落在下拉栏区域内，如果覆盖层透传导致点击无效，可尝试将窗口置于前台后操作。

**Q：修改模板后，下次启动又失效了？**  
A：模板会保存在 `templates/` 文件夹中，请确认该目录有写入权限，且程序正常退出（不要强制结束进程）。
